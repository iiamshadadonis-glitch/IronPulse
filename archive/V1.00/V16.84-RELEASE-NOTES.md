# Urgent Casting V16.84

## Included changes

- Inbox app-level Block / Unblock for every unified social conversation. Blocking preserves the existing history, stops manual replies and automation, and suppresses future inbound storage until the contact is unblocked.
- Faster Inbox switching using immediate selection, a per-conversation cache, stale-response protection, background mark-read, and no full Inbox reload after sending.
- Chatbot DM image and document attachments now upload to Google Drive. The attached file name is clickable and the × action removes it.
- Telegram Bot API integration with connection testing, secure webhook registration, Inbox messages, replies, images, documents, inline buttons, Chatbot DM flows, and target group/channel publishing.
- Sales is presented as one sidebar destination with internal Create Subscription, Plans & Offers, Bulk Import, and Product Placements tabs. Existing panel IDs, forms, loaders, and legacy routes are retained.

## Deployment

Deploy the complete replacement directory through the existing Cloudflare Pages workflow. No D1 migration is required for V16.84.

For Telegram, create a bot with BotFather, paste its token in **Settings → Integrations → Social Media → Telegram**, enter the optional target group/channel ID or @username, and click **Connect Telegram**. Add the bot as an administrator when it must publish to a channel.
