Run `npm run test:dance-v1.55` for the current code regression suite. For browser checks, provide `DROPBEAT_PLAYWRIGHT_MODULE` (installed Playwright), `DROPBEAT_CHROMIUM_PATH` (Chromium executable) and `DROPBEAT_TEST_OUTPUT` (outside the project), then run the listed browser commands. Historical release tests retain their historical size/version expectations.

## Archive verification

The complete ZIP uses standard Deflate without encryption, split volumes or ZIP64. Delivery verification checks CRC integrity with Python and Info-ZIP, independently extracts with both tools and compares every extracted file to the tested project using SHA-256. It also checks duplicate/case-colliding names and Windows-compatible paths. The saved download copy is checked again for byte equality, CRC and entry hashes. `V1.55-MANIFEST.sha256` covers every other project file.
