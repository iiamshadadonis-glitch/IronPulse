# V1.48 completed fixes

All V1.48 presentation changes apply only at the existing mobile breakpoint, 760px and below. Existing theme values, source handlers and desktop interactions are retained.

- Added one reusable circular checkbox component across Admin, Coach and Student views. It retains the actual native checkbox, checked/disabled/indeterminate state, keyboard interaction and original change handlers. Associated labels have 48px minimum touch targets; cleanup cards toggle selection when their non-action content is tapped. Destructive selection uses the existing danger color.
- Safe Cleanup review headers have consistent padding, a title and Close icon on one row, and clear spacing before warnings. The delete FAB stays 24px from the bottom/right plus safe-area insets, adapts its contrast in dark mode, and opens the original action sheet and confirmation.
- Storage summary and cleanup statistic boxes use theme surfaces, text and border variables in light/dark mode. Available-space indicators retain the original good/watch/warn/danger classes and corresponding status colors.
- Select fields and mobile selector buttons use a downward variant of the existing global disclosure SVG, with matching stroke, proportions and theme color. Existing bottom-sheet selection and original select/date/time values remain authoritative.
- Product Images, social media, Brand Settings, bulk CSV imports and portal forms use one native upload factory. Dashed upload areas choose suitable image/media/document labels and icons, retain the original file input and FileList, and update filenames after selection/reset.
- Client Details → Payments uses clean two-column label/value rows with thin dividers. Subscription action icons have consistent 40px dimensions and spacing while retaining their original actions.
- All four Growth Analytics modes keep time controls on the left and chart controls on the right, with more comfortable time-label padding and centered chart icons, including narrow 320px screens.
- Analytics Calendar list rows use the same 20px/1.8-stroke disclosure component as Settings → Pages, with a correctly sized right column and no clipped/duplicate indicator.
- All mobile refresh icons use one open clockwise arrow with a visible gap, preserve their existing outer dimensions, and inherit the current primary theme color. The icon requires no external library/runtime request.
- V1.48 assets load once and dashboard HTML remains uncached so normal refreshes discover the new presentation assets.

All V1.47 files are retained. No database migration is required. Original business handlers, API/database integrations, save/import/refund/payment logic, theme settings and features are preserved.
