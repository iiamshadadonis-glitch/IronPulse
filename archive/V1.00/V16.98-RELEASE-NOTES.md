# V16.98 release notes

## Visitor and repeat-visitor dialogs

- Restored a fixed six-column grid: Visitor / Lead, Latest Visit, Visits, Visitor Type, Sources and Pages.
- Name opens Client Details when a linked lead exists. Phone, device ID and IP address are displayed once in a stable vertical order.
- Latest visit date and time are separated. Visitor type and sources use readable theme-compatible badges.
- Visitors and Repeat Visitors share the same renderer, while the Repeat view keeps the existing repeat-only API filter.

## Visitor context and consent

- Cloudflare edge IP and the first-party visitor/device ID are recorded as operational security and visit-continuity context.
- Analytics and advertising consent remain separate. Optional analytics/advertising tags and audience use stay disabled unless the visitor chooses **Allow Optional**.
- Closing the cookie preference dialog is treated as **Only Necessary**. No optional advertising cookie is installed by closing or ignoring the dialog.

## Webinar reminders

- Reminder rows now have Amount, Unit, and Timing (Before event or After event).
- Every row displays a live, human-readable send date/time before the event is saved.
- Backend reminder offsets support both before-event and after-event delivery without a database migration.

## Brand Settings → Email

- Added editable automatic email templates for Schedule Confirmation, Meeting Reminder, Invoice, and Payment Statement.
- Subject, heading, capsule text and message body can be changed while existing brand colors, logo, details, action buttons and PDF attachments stay controlled by their workflows.
- Template settings use the existing settings storage, so no D1 migration command is required.

## Deployment

Deploy this complete replacement through the same Cloudflare Pages method used for earlier replacement ZIPs. This release does not require `npm run d1:migrate:remote`.
