# V1.47 completed fixes

These changes apply only at the existing mobile breakpoint (760px and below).

- All Brand Settings full-screen editors use a viewport-height flex column, with a fixed header and footer and an independently scrolling input/review body. This includes Brand Profile, Home Banner, Studio Images, Website Colors, Theme, Social Media, Legal Entity, Taxes, Checkout, Notifications, Coupons, Maps, Reviews, Email templates, Coach Settings and Login editors.
- Wizard headers have 16px × 20px padding. Step indicators use the same balanced grid as the About Us wizard, rather than clustering together on the left. Form content has consistent inset spacing below the steps.
- Footer buttons retain the shared Back/Continue/Save classes and sizing from About Us and Dance Tip forms. Buttons share the available row width, the step count stays centered, and the footer includes safe-area padding at the bottom edge.
- Website Colors/Theme and Checkout use the shared view-segment class. Selected tabs have the current primary theme color with white text; inactive tabs remain transparent with legible theme text. Existing tab routing is retained.
- Versioned V1.47 assets are loaded once; dashboard HTML remains uncached so an ordinary refresh discovers the updated mobile styles.

All V1.46 files are retained. Original form controls, file input bindings, validation, read-only reviews, submission handlers, API/database operations, integration settings and theme values are preserved. Desktop presentation is unchanged.
