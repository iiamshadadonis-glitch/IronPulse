# DropBeat V1.53 — mobile portal polish

Complete replacement project, continuing V1.52. The newly attached V1.51 archive is byte-identical to the earlier V1.51 source, so the completed V1.52 Customers fixes are retained.

All new layout and interaction changes apply at 760px and below.

- **Global dashboard headers:** standard 12px/16px padding, one aligned flex row and space for the title, theme toggle and avatar. Admin, Student and Coach use a transparent 40px circular menu control with one clean SVG icon; legacy pseudo-element decorations are suppressed on mobile.
- **Profile shortcut:** Student and Coach header avatars are tappable and use the existing Settings route. Student navigation explicitly selects Profile even if Login Information was the last settings tab visited. The original image node and profile bindings are retained.
- **Session cards:** Dashboard weekly schedules and Sessions use a vertical sequence: class title, coach, date/time, then the status or action. Status pills fill the footer width. Existing session dates, availability checks, status colors and Join/Start/End actions are unchanged.
- **Payment Statement:** title and close control align at opposite edges. Statement metadata and three summary values have content-sized heights, compact padding and mobile typography. The original filter trigger becomes a purple FAB above the actual footer height, with space in the scroll body so final records remain accessible. It still opens the same global filter sheet with the existing Apply behavior, date controls and odd/even grid rule. The original PDF action remains in the footer.
- **Tickets:** the mobile screen is a navigation hub with full-width Create a Ticket and Your Tickets rows. Create uses the existing full-screen form and Review; Your Tickets opens the original ticket list/empty state in a separate full-screen overlay. Original validation, form controls, POST handler and replies remain intact.
- **Shared navigation rows:** the existing global row/disclosure component uses consistent 56px minimum height, 14px/600 label typography and 12px spacing for stacked rows. A scoped CSS cascade layer protects these dimensions from older generic button rules. Login Information and Connect Google Account use this shared styling.
- **Desktop restoration:** resizing restores original avatar/menu nodes, theme-button placement, ticket sections and navigation controls. Desktop session grids and all other desktop layouts remain controlled by their existing styles.

This release adds a presentation/navigation adapter and stylesheet. Existing portal business scripts, database configuration, migrations, financial logic, native upload bindings, theme files and the V1.52 Customers implementation are byte-identical to V1.52. Middleware changes only the release response header; the HTML files add the new versioned assets.

See V1.53-VERIFICATION.md for tests and scope. Earlier version notes are retained as release history.
