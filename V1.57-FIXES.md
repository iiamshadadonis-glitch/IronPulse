# V1.57 fixes and new Layout editor

This complete replacement builds on the supplied V1.56 project. It preserves all original files and adds the Visual Layout Editor and the requested responsive Buttons corrections.

## Visual Layout Editor

- Added **Settings → Pages → Layout**, also available through the existing mobile More menu.
- A shared theme registry generates the wireframe from the active saved theme: DropBeat Original, Casting Editorial, Studio Spotlight or Modern Minimal. Studio Images is available only in themes that display that block.
- The wireframe represents the brand/header actions, main navigation and links, home banner, class highlights, studio introduction/images, plans, How It Works, Student Stories, class notice and footer content.
- Pencils open a padded block editor with a read-only Review step. Supported settings include shared names, visibility, width, alignment, vertical padding, grid spacing and column counts. Header Checkout and Trial destinations use the existing validated Button Dictionary destinations.
- Desktop Layout and Mobile Layout share content/names but retain separate constraints and home-section order. Desktop supports drag reordering; up/down controls work on both devices.
- Removals are staged until publication and can be restored. The renderer keeps the original DOM nodes and their event handlers. Removing a presentation block does not delete database records or disable the Admin's editing tools.
- Each theme retains its saved layout. A saved theme change redraws the editor; a theme change cancels an unexecuted live-save warning and prevents a previous theme's draft from being saved into another theme.
- **Save Layout Changes** opens a centered desktop warning or a mobile bottom sheet. Both browser and API require exact lowercase `confirm` before the red **Execute Changes** action can save.

## Shared names, persistence and cache freshness

- The existing D1 `settings` table stores a `visual_layout` document. Existing navigation overrides and the Button Dictionary remain the sources for their corresponding names and destinations. No migration is needed.
- Layout, navigation names and button changes are saved in one guarded D1 batch. The guard checks the source layout, theme/settings, navigation and button values; stale or concurrent saves are rejected instead of silently overwriting another edit.
- Shared names update public navigation, applicable public headings, Admin sidebar/hub entries, related section titles, header previews and Header Order labels. Existing page URLs and aliases remain intact.
- Checkout/Trial/Login labels are synchronized with the Button Dictionary. Its existing Reset action still resets only button data.
- Successful Layout saves invalidate the Layout, dictionary and public site cache keys. Dictionary, theme and navigation saves also invalidate the Layout cache.
- Browser reload/return checks request fresh configuration with `X-DropBeat-Revalidate: 1`; those API responses are `no-store`. Concurrent requests are deduplicated. Normal cached requests retain a 60-second Edge cache; no new polling or window-focus timer was added.
- Cloudflare Cache API deletion affects the current data center. The explicit browser freshness path bypasses that cached copy, so reloads do not depend on a global CDN purge. See the official [Cache API documentation](https://developers.cloudflare.com/workers/runtime-apis/cache/) and [D1 batch documentation](https://developers.cloudflare.com/d1/worker-api/d1-database/).
- Private Admin layout metadata and Admin button overrides are excluded from persisted public cache entries. An unavailable public API keeps the last good layout and usable original controls.
- Updated older naming decorators to respect explicitly configured names. Home-section ordering is scoped to Home, leaving other page layouts alone.

## Buttons UI corrections

- Mobile categories use the shared compact Growth Analytics segmented control, including its active pill and keyboard behavior.
- Compact numbered rows use 14px labels, 24px badges, 16px pencil icons and padded edit touch targets. Long labels can expand without clipping.
- Desktop categories are vertically stacked native accordions; the mobile category toggle is hidden on desktop.
- A shared Pages workspace controller ensures only the selected primary tab is active and restores the previous Pages views when leaving Buttons/Layout.
- Removed the duplicate Refresh rendering: the Buttons action contains one visible refresh SVG.
- Existing responsive edit/review modals, exact typed-confirm warnings, Reset safeguards and native button actions are retained.

## Preserved scope

The existing financial, authentication, booking, upload/import, CRM and integration handlers remain authoritative. No theme palette, dependency lockfile, migration, D1 binding or deployment configuration was changed. The source comparison and executed regression evidence are in `verification/v1.57/`; detailed test scope is in `V1.57-VERIFICATION.md`.
