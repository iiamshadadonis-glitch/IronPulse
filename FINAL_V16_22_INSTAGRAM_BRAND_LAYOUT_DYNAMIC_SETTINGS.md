# FINAL V16.22 – Instagram brand layout and dynamic brand-settings driven image styling

This version keeps the Instagram publishing logic from V16.21 intact and improves only the branded Instagram image composition.

- Improves the lower branded section so the post looks closer to the branded email layout.
- Uses the brand identity dynamically from **Brand Settings / site settings**:
  - brand name
  - tagline
  - logo
  - primary color
- Adds a clearer branded layout:
  - logo on the left
  - brand name beside the logo
  - tagline below the brand name
  - “APPLY NOW” cue on the right
  - cleaner title block with spacing control
  - subtle branded border using the current primary brand color
- Title font sizing now adapts better to shorter and longer audition titles.
- Existing Instagram auto-publishing logic is preserved; this is a visual/layout add-on only.

## No change

- No change to webhook logic.
