## Preservation and test limits

The supplied V1.56 archive passed CRC verification before extraction. The comparison in `source-scope.json` records all 40 changed original paths and all added paths. The 1,606-file protected hash inventory is checked by the current regression command.

Financial/payment, booking, authentication, upload/import, CRM, automation and integration handlers, theme definitions, dependency lockfile, database migrations/bindings and deployment configuration remain unchanged. Changes to existing backend files are limited to configuration/cache integration, version metadata and module delivery. Older text decorators receive presentation guards so they respect configured labels.

These are local automated tests. Production Cloudflare/D1, live payment gateways, email delivery and real OAuth accounts were **not** contacted. No deployment was performed. The tests establish the exercised handler, SQL, UI and cache behavior; they do not claim live-production verification.

Reproduce code checks with Node.js 24 or later and `npm run test:dance-v1.57`. Browser checks require installed Playwright and Chromium through `DROPBEAT_PLAYWRIGHT_MODULE` and `DROPBEAT_CHROMIUM_PATH`; set `DROPBEAT_TEST_OUTPUT` outside the project. Historical version-specific tests retain their historical size/version expectations; use the V1.57 entry point for this release.

## Replacement archive verification

The delivery process uses one complete `DropBeat-V1.57` project root, standard Deflate compression and Windows-compatible paths, without encryption, split volumes or ZIP64. Python and Info-ZIP both test archive integrity and independently extract it. Every extracted file and the project manifest are compared to the tested source with SHA-256; code regressions are also run from the extracted project.

The saved downloadable ZIP is checked again for byte equality, CRC integrity and every entry hash before delivery. `V1.57-MANIFEST.sha256` covers every other file in this replacement, including the successful regression evidence.
