# Final V7 — Self-Learning Admin UI

This build is additive to the supplied V6 project.

## Main additions
- Compact Favorites table.
- Gmail-only compose links from Client Details.
- Maps & Reviews spacing and location toggles.
- Solution-oriented help cards for Social Media, Tracking, Dashboard, Home Banners, Plans & Offers, Ad Integrations and Admin Security.
- About Us optional cover image URL/upload with crop editor and public rendering after the first paragraph.
- Pages stray-chevron suppression.
- Website Colors collapsed help card, temporary browser-local preview and reset/save safety.
- Immediate Site Settings toggle for showing/hiding admin information helpers.
- Audition Link Extension guidance clarified as optional and without `/blog/` in the input example.

## Theme preview safety
Theme previews are stored only in the current browser and expire automatically after ten minutes. They are not saved to the database until Save Settings succeeds. Leaving Site Settings restores the admin UI to the last saved theme; logging out clears the temporary public preview.
