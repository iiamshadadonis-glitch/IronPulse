# V16.83 Themed Automation Help

V16.83 is an additive presentation and guidance update for the Automation Flow Builder libraries.

## Changed

- The Help & Instructions launcher reuses the established Admin `uc-info-btn` component, its 34 × 34 circular layout, and the existing outlined information SVG.
- The help-card return action reuses the established `uc-info-back-btn` component and outlined circular return SVG.
- Automation-specific placement rules only keep the shared controls aligned within the Flow Builder header. They do not introduce replacement colors or button dimensions.
- All examples rendered by the shared automation help module are generic and suitable for any business. They cover keywords such as `LINK`, product or service information, pricing, support, live availability, checkout, and follow-up timing.

## Preserved

- Chatbot DM, Chatbot Comments, Lead Nurturing, and Comment Triggers DM logic.
- Platform selection, content blocks, flow connections, validation, activation, integrations, and delivery rules.
- Existing Admin and website color themes.
- D1 read safeguards, thresholds, schema, and migrations.

## Deployment

Deploy the complete V16.83 replacement. No new migration is required.
