# V16.86 Release Notes

## Admin navigation and workspaces

- Added a single **Business Operations** navigation group containing Sales, Orders & Leads, and Customers.
- Preserved the existing dashboard shortcuts and underlying panel loaders while routing them into the new nested workspaces.
- Added clear Orders lifecycle tabs for New, Pending, Existing, Cancelled, and Cancelled Subscriptions.
- Added Refunds tabs for Razorpay, Stripe, PhonePe, Manual Record, and Refund Records, including Refund Records search.
- Renamed Contact Leads to **Inquiries** and retained its All/New/In Progress/Resolved workflow, search, refresh, and export actions.
- Retained Requests status tabs and added a current-view Excel export.
- Added Customers workspace tabs and focused add/list views for Subscribers, Unsubscribed, One-Time Users, and Favorite Clients.

## Telegram integration help

- Moved the themed Telegram information button inside the expanded Telegram dropdown.
- Reduced its footprint and added safe spacing.
- The same location now switches between the information icon and circular back icon while the help view is open.

## Branded Gmail payment offers

- Added an Email Subject field and **Send Offer via Gmail** action to both Subscription Link and One-Time Payment Link forms.
- Gmail sending first creates the existing secure payment link, then sends it through the connected Gmail account using the existing branded email renderer.
- Missing email/subject fields are highlighted with a clear diagnostic.
- Disconnected Gmail returns a clickable recovery action that opens the exact Gmail integration card.

## Safety and compatibility

- Existing payment-link generation, order actions, refund providers, customer records, navigation shortcuts, brand colors, and integration logic remain in place.
- No D1 safeguard, read-budget, schema, or migration changes are included.
