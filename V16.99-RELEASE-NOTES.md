# V16.99 Release Notes

## Visitor and repeat-visitor dialogs

- Orders identity data as Name, Mobile Number, IP Address, Location and Device ID; anonymous rows begin with IP Address.
- Adds an Excel-compatible export beside Close for Visitors and Repeat Visitors.
- Includes analytics-consent and advertising-consent columns in the export so downstream use can be filtered responsibly.
- Keeps the existing visit, visitor-type, source and page journey presentation.

## Brand Settings → Email

- Replaces duplicate disclosure markers with one themed SVG dropdown control.
- Adds complete editable email sections: subject, heading, capsule, greeting, pre-summary message, summary title and labels, post-summary message, footer note, button label and destination.
- Adds independent Preview Email and Save Template buttons inside every dropdown.
- Adds Payment Successful and Payment Failed / Retry templates.
- Connects the saved templates to webinar confirmations/reminders, invoice/statement delivery, successful-payment receipts and failed-payment recovery.
- Explains that before/after reminders are calculated from the event date and time, not the event title.

## Deployment

- No manual D1 migration command is required for this update.
- Static asset URLs use the V16.99 cache key.
