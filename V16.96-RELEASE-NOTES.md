# V16.96 Complete Replacement

## What changed

- Business Ops and Orders & Leads now use the same red notification treatment as the rest of the admin panel. Parent alerts are acknowledged once opened and remain hidden after refresh until a genuinely new record arrives. Orders and New Orders retain their unresolved counts until the order is moved to a final status and saved.
- Business Ops now includes Contacts: search, row selection, primary contact details, alternate identity dropdowns, selected/all CSV exports, and a separate advertising-consented marketing export.
- Connected Inbox conversations display the confirmed CRM name when one is known. Clicking that name opens a contact-only modal; the provider profile link remains separate.
- Automation editors support an `@` attribute picker. Known tokens resolve from the unified contact; `@ClientName` safely falls back to “there”, while a sentence containing another unavailable selected attribute is omitted to avoid malformed personal messages. Literal email addresses remain unchanged.
- Website visit context stores Cloudflare’s trusted edge IP/country only after Analytics or Advertising consent. IP/device context is never used to merge two people and is excluded from the marketing-ready CSV.
- Heat Maps Help & Instructions now explains Heat, Scroll and Attention maps, Top Engagement Elements, filters, blank reports, examples and practical actions.

## Deployment and D1

This replacement does **not** require `npm run d1:migrate:remote`. The existing API middleware runs the guarded, additive schema update once after deployment. Replace/deploy the code normally; the first API request adds the V16.96 columns and updates the schema marker. Existing data and logic remain intact.

## Privacy note

The operational export may include consented IP/device context for fraud/support analysis. The separate marketing-ready export excludes those fields and only includes contacts that granted advertising consent. Always confirm the chosen advertising provider’s audience and consent requirements before upload.
