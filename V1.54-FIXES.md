# V1.54 completed fixes

This is the complete V1.53 project with the following mobile presentation fixes included. All V1.53 functionality and earlier fixes remain in the replacement project.

## One shared mobile header

Admin, Coach and Student now use the same header layout builder and stylesheet. The header spans the viewport, has consistent 16px horizontal padding and a 64px content height, and respects the top safe area. The original menu, title, theme control, account photo and home link are moved into common leading/title/action slots rather than duplicated or rebound.

Hamburger, theme and avatar controls have bounded 40px circular touch targets; menu and theme SVGs are bounded to 22px. Existing menu dismissal, theme persistence and avatar-to-Profile behavior are retained. Switching to desktop restores the original nodes and their original positions. The light/dark surfaces and brand palette come from the existing theme variables.

## Readable mobile dark mode

The older shared mobile foreground token could fall back to a light-mode dark-text token in the Student and Coach portals. Mobile primary and secondary text now resolve through each portal's existing dark-aware theme variables. Clickable rows and their labels inherit the readable foreground; inactive tabs use the secondary foreground.

The same rules cover Student settings labels, modal headings, read-only review data and secondary actions. Payment Statement metadata/summary boxes and neutral payment-status pills also use theme surfaces instead of retaining pale light-mode backgrounds. Existing semantic success/warning/danger status colors are retained.

## Primary Filter Apply action

The existing shared filter sheet's Apply control now uses the primary brand background, white text, a 48px minimum height, standard rounded corners and a full-width layout. Its footer has 16px padding and bottom safe-area clearance. The original filter form, odd/even grid, date values, submit handler and dismissal remain intact.

## Scope and preservation

- New runtime files: `public/assets/dropbeat-global-header-v1-54.js` and `public/assets/dropbeat-mobile-contrast-v1-54.css`.
- The three portal HTML entry points load these assets after the retained V1.53 adapter.
- All new CSS is restricted to viewports at or below 760px. Desktop header nodes are restored at larger widths; no desktop palette or layout rules are added.
- 1,562 original V1.53 files remain byte-identical, including every existing business script, upload/form/filter controller, theme file, API implementation, migration and database configuration. The middleware change is only its release response header.
- Seven original files changed: the three HTML entry points, package/version metadata, the current deployment-version assertion and the release-only middleware marker. Additional files are the new UI assets, regression tests, fix documentation and verification evidence.
- There are no database migrations, dependency additions, fetch loops, new API calls or changes to payment/subscription calculations in this release.

See `V1.54-VERIFICATION.md` for the checks actually executed, their scope and reproduction commands.
