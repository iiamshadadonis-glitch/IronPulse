# V16.85 — Admin responsiveness hotfix

This is a complete replacement package based on V16.84.

## Fixed

- Removed the page-wide mutation loop that could repeatedly rewrite Telegram diagnostics and make the admin page unresponsive.
- Limited Inbox block-button observation to the Inbox workspace and coalesced updates to one animation frame.
- Made Telegram status rendering idempotent so unchanged status text is not written repeatedly.
- Removed the retired Sales dropdown from the DOM after the single Sales workspace is created.
- Updated the authoritative sidebar builder to create Sales as one direct option, preventing later navigation refreshes from recreating the retired dropdown.
- Added defensive duplicate removal so only one Sales option remains visible.
- Avoided loading a Sales data source merely because the admin dashboard initialized; Sales data loads only when its workspace or subsection is opened.

## Preserved

- All V16.84 Inbox blocking, faster conversation switching, Google Drive attachments, Telegram, automation, and Sales workspace capabilities.
- Existing public website behavior and color theme.
- Existing D1 migrations, safeguards, read budget, polling, and database logic.
