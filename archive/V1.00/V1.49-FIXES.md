# V1.49 completed fixes

This is a complete replacement project based on the supplied, verified V1.48 ZIP. All V1.48 files and earlier fixes are retained. The existing primary/accent colors, saved theme settings, credentials, integrations and database schema remain in use.

1. **Dark-mode contrast across the three dashboards.** Informational and warning boxes, success/error alerts, relevant child cards and sticky selection rows now use semantic theme surfaces, text and borders. Safe Cleanup's permanent-deletion warning and “Select all shown” row remain readable in Dark Mode. Desktop Light Mode helper styling is preserved.
2. **Client Details → Payments on mobile.** The main tab now contains two compact disclosure rows: “Subscriptions & Payments” and “Payment Records.” Each opens a separate full-screen, scrollable view with its own Close action. The views retain the original live subscription controls, transaction records, page-size/pagination handlers, gateway refresh and statement actions. Refreshes and pagination keep the selected destination open. Closing returns to the two-row menu. Desktop retains the inline layout.
3. **Subscription cancellation safety.** Recurring-subscription Cancel/X controls have a theme-aware red border and icon, distinct from Play, Pause and Refresh. Their original cancellation warning and gateway behavior remain intact. Subscription details retain compact, divided key/value rows instead of thick pill boxes.
4. **Schedule loading and navigation on mobile.** Schedule, Leaves and Holidays update immediately while a request is pending or has failed. A 15-second deadline, cancellation of superseded requests, caught errors and an explicit Retry state replace indefinite loading. Late responses cannot overwrite newer results. Mobile reads are paginated at the server; “Load more schedule records” retains access to subsequent pages. Coach assignments are limited to the current coach page. The default desktop response and existing schedule/leave/holiday/class-change actions are preserved.
5. **Pages sub-options and modal headers on mobile.** Nested Website Header Order entries use the same compact, single-row number/input/action layout as parent entries. Redundant generated “Actions” labels and old grid headers are hidden. Existing reorder, rename and Edit handlers stay attached. Full-screen headers receive consistent 16px/20px padding, readable copy and a correctly aligned Close icon. Legacy document helpers retain their required direct-child Close anchor.
6. **Connected integration toggles on mobile.** Styled switches are correctly distinguished from circular selection checkboxes. Social Media, SEO, Storage, Email & OTP, Payments and Ad Networks connected-list switches stay at 44×24px with an 18px thumb and the existing primary brand color when enabled.
7. **Global desktop drag-and-drop uploads.** Admin, Coach and Student file fields share a responsive dashed upload zone with contextual CSV/image/video/file instructions, a centered icon, file names, accepted formats, drag feedback and keyboard focus styling. The original input, name, FileList, accept/multiple/required/disabled flags and change handlers remain attached. Supported dropped files enter the original workflow; invalid formats and disabled fields are handled without submitting. Existing hidden pickers used by custom upload buttons remain hidden and keep their original parent/handler. Mobile continues to use the compact native upload area.
8. **Real CSV import blocker fixed.** The global pending-button indicator disables the submitter before the importer starts. The importer now guards actual concurrent imports rather than treating that visual disabled state as a duplicate request. This restores the original Import Plans API call from desktop clicks and dropped CSV files without changing CSV parsing, plan validation or persistence.
9. **Release delivery.** Current dashboard shells load one V1.49 controller and one shared component module, with updated cache build keys including the Schedule loader and importer. The full project includes prior files, Functions, migrations, configuration, tests, deployment guidance and verification records. No new migration is required.

## Scope and compatibility

- Mobile layout rules use the existing 760px breakpoint. Desktop layout is preserved apart from the explicitly requested upload zones and global Dark Mode contrast correction.
- No payment, refund, cancellation, email, publishing or cleanup action is executed just by opening a new navigation row. Existing submit and confirmation handlers remain authoritative.
- Backend changes are restricted to optional mobile pagination of the existing Schedule GET response. Existing POST handlers, authorization, financial calculations and database integrations are retained.
- The executed checks and their real-world limits are documented separately in `V1.49-VERIFICATION.md`.
