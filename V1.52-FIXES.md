# DropBeat V1.52 — Customers mobile navigation

This is the complete V1.51 project with the following scoped additions for Admin → Business Ops → Customers. The mobile breakpoint remains 760px.

- Subscribers, Unsubscribed and One-Time Users now expose one compact clickable action row with the existing global, theme-colored disclosure icon. The old mobile accordion heading, caret, nested box and blue “Open…” launcher are removed from the visible flow.
- Each row opens its original full-screen form wizard directly. The existing inputs, required-field validation, final Review step, save handlers and API payloads are retained.
- Add / Import Subscribers offers compact Add Subscriber / Import CSV navigation inside the full-screen flow. CSV instructions, the sample download and uploader are inside the import wizard rather than the main screen. Import CSV uses the global dashed native upload component and a Details → Review flow before the original Import Subscribers action.
- The original file input, FileList and CSV importer are preserved. Changing modes does not discard the selected file or manual draft.
- The mobile form uses a full-height flex layout with a padded header, a scrolling body and an anchored footer, including safe-area spacing. An in-progress form stays visible when the existing customer loader updates the underlying list selection.
- Navigation rows and mode tabs use the established navigation marker, preventing the existing asynchronous-button helper from incorrectly replacing them with “Importing…”.
- Closing restores navigation focus. Resizing to desktop closes the mobile form and restores the original accordion, nodes, input placement and button attributes. Re-entering mobile does not duplicate upload inputs or navigation rows.

Existing theme variables, subscriber/manual-record handlers, public caching, database integrations, deployment configuration, payments and all other V1.51 features are preserved. Desktop upload behavior remains the shared V1.51 drag-and-drop behavior.

See V1.52-VERIFICATION.md for the tests actually executed. Older V1.xx reports are retained as release history; use the V1.52 report for this package.
