No deployment was performed. Current successful logs and scope are included under verification/v1.53. Earlier release reports remain history.

To reproduce browser checks, provide `DROPBEAT_PLAYWRIGHT_MODULE` (installed Playwright package), `DROPBEAT_CHROMIUM_PATH` (Chromium executable) and `DROPBEAT_TEST_OUTPUT` (outside the project), then run the listed browser commands.

The complete ZIP uses standard Deflate without encryption, split volumes or ZIP64. Before delivery it is checked with Python and Info-ZIP CRC verification, independently extracted with both tools and compared to the tested source using SHA-256 for every file. The exact saved download is checked again for byte equality, CRC and entry hashes. Runtime dependencies, Chromium binaries and browser screenshots are excluded.
