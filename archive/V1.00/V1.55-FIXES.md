# V1.55 completed fixes

The complete V1.54 project and its earlier fixes are retained. This release changes only the shared mobile header presentation requested for Admin, Coach and Student.

## Exact icon dimensions and shapes

- Hamburger: 32px by 32px visible rounded-square container, 8px corner radius, centered 16px by 16px SVG and a subtle border using the existing theme divider color.
- Dark/light toggle and existing Home action: 32px by 32px visible circles with centered 16px by 16px SVGs.
- Controls cannot grow or shrink: width, height, minimum/maximum dimensions and flex basis are constrained in the shared stylesheet.
- The account photo remains at its existing size and retains the Profile shortcut.

## Larger invisible touch areas

Each 32px icon control has a centered, transparent 48px by 48px hit area. This supplies the equivalent of 8px invisible padding on every edge. The action group uses a 16px flex gap, rather than button margins, so neighboring enlarged hit areas do not overlap. Taps in the transparent area activate the original button or link directly; no proxy click handler or duplicate event binding was added.

## Original behavior and desktop retained

The Admin Home control previously contained a text character. The existing shared header adapter now replaces only that character with a small outline SVG on mobile. It keeps the same anchor, URL and accessible label, and restores the original children when returning to desktop. Existing menu, theme, avatar, authentication and navigation handlers remain in place.

All stylesheet edits are inside the existing mobile header layer at a maximum viewport width of 760px. The V1.54 dark-mode contrast and filter-button rules are byte-identical. Theme colors are still read from the existing variables; no palette was changed.

## Change scope

- Runtime presentation edits: `public/assets/dropbeat-mobile-contrast-v1-54.css` and `public/assets/dropbeat-global-header-v1-54.js`.
- The three portal HTML files use a V1.55 query on those two assets so cached V1.54 copies are not reused after deployment.
- 1,583 original V1.54 files are byte-identical. All existing business scripts, form/upload/filter controllers, payment/API/database functions, theme files, migrations, configuration and dependency lockfile remain unchanged.
- Nine original files changed: the two presentation assets, three HTML asset references, package/version metadata, release response header and current-version deployment assertions. Added files are tests and documentation/evidence.
- No dependencies, API requests, database reads/writes, payment calculations or business actions were introduced.

See `V1.55-VERIFICATION.md` for the executed tests and test scope.
