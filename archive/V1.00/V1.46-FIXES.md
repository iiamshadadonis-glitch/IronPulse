- **Banners:** Home Banner and Studio Images launch side by side. Studio Images has Details and Review, native media selection, stable file labels and compact filename summaries. Clear/reset remains available through the form header actions, and upload captions reset with the original file controls.
- **Website Colors / Theme:** separate field ownership, one relevant launcher per segmented tab, deduplicated appearance controls, compact HSL controls and padded previews. Theme review contains only the selected frontend theme.
- **Social links:** all platforms appear together, followed by Review. Compact platform/toggle rows and meaningful platform-specific URL and Visibility labels replace numeric array labels.
- **Legal / Taxes:** two independent menu actions open their own two-step wizards. Legal Entity contains its toggle, name and address; Taxes contains only tax settings. The final Taxes action calls the original Save Taxes handler.
- **Checkout:** Behaviour settings share one input step; Notifications and coupons use their own two-step editors. Notification reviews are read-only. Compact coupon records retain status and Edit/Delete actions.
- **Maps / Reviews:** the selected Brand tab stays visible. Map settings start with the main toggle and API key, then dynamic locations. Remove Location remains a working compact inline icon. Google Reviews opens an Edit / Refresh Reviews Now action sheet; only Save appears on the final review.
- **Storage:** one header help action, an available-space progress bar and a normally sized upgrade link. Cleanup lists use compact selection controls without SELECT headings. A trash FAB opens the original guarded delete choices. Individual record details open a compact bottom sheet; deletion confirmation stays above it.
- **Email:** compact title-only template navigation; role-based template editors now have a real scrollable body, padded fields and an anchored footer. Review uses readable key-value rows. Preview, Revert and existing save confirmations remain available.
- **Coach Settings:** moved report filters remain accessible to the original loader. Mobile GET loading has a 15-second bound, error state and Retry; successful retries clear prior errors. Compact two-step onboarding/leave settings keep native selection sheets.
- **Login:** four consistent mobile navigation rows; contextual email help sits inside its row. Two-step full-screen editors have properly spaced headers, scroll areas and footers. Password reviews show presence only. Read-only connection fields show their configured/empty status.
- **Shared mobile presentation:** fixed field ownership, toggles, input spacing, safe footer placement and two-column review dividers; long filenames and URLs truncate without horizontal overflow. Reviews update on actual input changes rather than repeated paints. Legacy Brand heading updates are idempotent.
- **Delivery:** V1.46 assets and changed legacy scripts use current cache-busting URLs. Middleware injects one current mobile controller. Existing themes, backend endpoints, database files, financial calculations and source action handlers are retained.
