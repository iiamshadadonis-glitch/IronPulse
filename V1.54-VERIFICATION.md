The V1.53 input archive was checked for CRC errors before extraction. 1,562 original files are byte-identical. Exact-delta checks also confirm that the three HTML files add only the new stylesheet/script, and the middleware only changes the release response header. Existing theme files, form/upload/filter controllers, financial and API code, migrations, bindings and database configuration were retained.

## Test scope and reproduction

Browser tests run the shipped HTML/CSS/JavaScript with local synthetic API data. Database tests use temporary SQLite fixtures. Live production Cloudflare/D1, payment gateways, email delivery and real OAuth accounts were not contacted; no deployment was performed.

Use `npm run test:dance-v1.54` for the current code regression suite. For browser reproduction, supply `DROPBEAT_PLAYWRIGHT_MODULE` (installed Playwright package), `DROPBEAT_CHROMIUM_PATH` (Chromium executable) and `DROPBEAT_TEST_OUTPUT` (a directory outside the project), then run the browser commands listed above. Historical version-pinned tests remain as release history.

## Archive verification

The complete ZIP uses standard Deflate with no encryption, split volumes or ZIP64. Delivery verification checks Python and Info-ZIP CRCs, performs independent extraction with both tools, and compares every extracted file with the tested source using SHA-256. It also checks ASCII/Windows-compatible paths and duplicate/case-colliding names. The exact saved download is checked again for byte equality, CRC and every entry hash. `V1.54-MANIFEST.sha256` covers every other project file.
