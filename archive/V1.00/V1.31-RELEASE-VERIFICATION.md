# V1.31 verification

The V1.31 automated gate validates asset order on every complete public HTML document, middleware-injected pages, dynamic blog/custom pages, Admin asset order, CSS structure, requested selector coverage, the Profile appearance ownership fix and JavaScript syntax.

It also compares SHA-256 hashes for the supplied V1.30 login, order creation, payment gateway, database schema, public application, portal schedule and webinar/meeting logic. These files must remain byte-for-byte unchanged.

Run:

```bash
npm run test:dance-v1.31
```

This command runs the V1.31 gate followed by the full inherited V1.30 regression chain.
