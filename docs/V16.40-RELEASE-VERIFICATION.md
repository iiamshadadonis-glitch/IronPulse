# Urgent Casting V16.40 — Release Verification

Targeted add-on release. Existing color theme and unrelated business logic are unchanged.

## Changes
- Pinterest Comments tab now shows each synchronized website-published Pin, opens the direct Pinterest Pin, and displays Pinterest API lifetime comment and reaction counts. Pinterest visitor comment text/moderation remains unavailable because Pinterest API v5 does not expose those general comment endpoints.
- Threads keeps visitor-comment deletion disabled. Own admin replies can be deleted. Edit Admin Reply uses a replace workflow: delete the admin-owned Threads reply, then publish the edited reply to the same visitor reply.
- X / Twitter connection now uses OAuth 2.0 Authorization Code with PKCE user context. Admin fields are Client ID + Client Secret; app-only Bearer Token/Consumer Key are no longer requested in the UI. Access-token refresh is supported when offline.access provides a refresh token.
- X OAuth callback: https://urgent-casting.com/api/admin/x-oauth/callback
- X Activity webhook remains: https://urgent-casting.com/api/webhooks/x-activity
