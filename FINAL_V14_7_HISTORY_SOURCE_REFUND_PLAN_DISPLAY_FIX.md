# Urgent Casting V14.7 — History, Source, Refund, Plan & Display Fix

This is an additive stability/UI release based on V14.6.

## Changes
- Client History distinguishes Website Enquiry from Website Request and uses live request type/status.
- Dashboard/Client Details show lead source tags.
- Subscription Overview customer names open Client Details only when an exact local CRM match exists.
- Edit Client candidate menus identify the origin of submitted values.
- Payment Records use deliberate date/time wrapping and wider columns.
- Invoice summary identifies offer discount source and coupon savings.
- Plan editor trial controls use two fields on the first row and a full-width Trial Length row; description/features are more compact.
- Plans grid no longer shows unnecessary selection checkboxes.
- Existing plan edits use form-scoped prefill so Plan Name, Badge and other values load reliably.
- Existing product images can be switched to Cover Image instantly without re-upload.
- Refund workspace keeps the paid record prefilled and approval shows customer identity, gateway and amount.
- Product Display places Yearly Plans under Select Pages, never under Select Plans / Offers.
- Yearly Plans uses the standard full website footer.
- Theme styling returns the original designer palette to a darker maroon presentation while still respecting configured theme colors.

No existing payment, gateway, subscription, CRM, refund, order or customer lifecycle logic was intentionally removed.
